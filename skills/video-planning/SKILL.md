# Video Planning

Read the brief and identify audience, outcome, runtime, language and aspect ratio.
Inspect supplied footage: probe its duration, generate a storyboard and view it.
For factual reviews, research current primary sources and record sources in the
project. Distinguish hands-on observations from documentation and staged demos.

Write a speakable script, estimated narration duration and a timed shot list.
Specify for each shot its source (supplied, original screen recording, licensed,
motion graphic or generated), dialogue, visible action, framing and transition.
Do not stretch a few clips with silent holds to claim the requested runtime.
Screenshots/recordings use the host's browser tools and actual visible state;
mask account data. No browser runtime or external clip downloader is included.

Route cuts to video-editing, overlays to video-overlays, generated shots to
video-generation. Keep rights/source records local. Final script and visuals must
match; a fictional host cannot be presented as an actual customer.
