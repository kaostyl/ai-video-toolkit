# Youtube Packaging

Watch or read the final transcript and inspect final timings before packaging.
Choose a clear search intent and an honest hook. Write a title, description with
sources/disclosures where needed, and chapter timestamps based on the actual MP4.
Make no unverified product claims or guarantees about ranking. Verify current
facts when including prices/features.

Use a supplied licensed still or an image tool actually available to the host
for an original thumbnail. Keep the composition readable at small size, concise
text and accurate subject matter. No image generation API or portrait is bundled.
Check current YouTube upload constraints before export, especially if changed.
Deliver files/concepts; uploading/publishing needs explicit user authorization.
