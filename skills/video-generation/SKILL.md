# Video Generation

Read docs/CLOUD.md. Discover the user's actual provider tools and current schemas
before constructing calls. The repository supplies workflows, not a Higgsfield
account, MCP server or guaranteed API model. Select the model from current tools
or official docs. Confirm native audio/lip-sync for speaking characters.

Write shot prompts with continuity references, dialogue, camera/action, duration,
resolution and format. Use clearly adult fictional cast when adults are requested;
label synthetic demos/presenters appropriately. Obtain current quotes before jobs.
Count generated seconds, images, audio and retakes; stay inside an accepted budget.
Do not automate offers restricted to manual use. Generate a short pilot, inspect
speaking/audio consistency, then produce the planned shots. Track IDs locally to
resume without duplicates. Assemble and QA the downloaded authorized outputs with
video-editing and video-quality. Never invent personal product usage or results.
